# Полная инструкция: запустить Hoop Flight и собрать APK для Android

Инструкция для новичка. Делай по порядку, ничего не пропуская.
Этапы 1–4 (игра запускается на компьютере и лежит на GitHub) — примерно час.
Этап 5 (APK на телефоне) — ещё 1–2 часа, в основном скачивание Android SDK.

---

## Этап 0. Словарик

| Слово | Что это |
|---|---|
| **Godot** | бесплатная программа-движок, в ней открывается проект и собирается APK |
| **GDScript** | язык, на котором написана игра. Похож на Python |
| **Git / GitHub** | хранилище версий проекта на компьютере / в интернете |
| **Коммит** | сохранённая точка «вот что я изменил» |
| **APK** | файл игры для Android |
| **JDK / Android SDK** | инструменты Google, без них APK не собрать |

## Этап 1. Программы (Windows)

### 1.1 Godot 4
1. https://godotengine.org/download/windows — качай **обычную** версию (НЕ «.NET»).
2. Распакуй ZIP, например в `C:\Godot\`. Внутри `Godot_v4.x-stable_win64.exe` — это и есть вся программа.
3. Запомни номер версии: шаблоны экспорта должны совпадать с ней точь-в-точь.

### 1.2 Git
1. https://git-scm.com/download/win — установи со стандартными настройками.
2. Проверка: `Win+R` → `cmd` → `git --version` → должна появиться версия.

### 1.3 GitHub Desktop (по желанию, новичку проще)
https://desktop.github.com — то же самое, но кнопками вместо команд.

### 1.4 JDK 17 (только для APK)
https://adoptium.net/temurin/releases/?version=17 → **Windows x64, JDK, .msi**.
Обычный путь: `C:\Program Files\Eclipse Adoptium\jdk-17.x.x-hotspot`.
**Именно 17.** С JDK 21/24 сборка падает с непонятными ошибками Gradle.

### 1.5 Android SDK (только для APK)
1. https://developer.android.com/studio — установи Android Studio, пройди мастер (Standard).
2. **More Actions → SDK Manager → SDK Tools** — поставь галочки: Build-Tools,
   Command-line Tools (latest), Platform-Tools, NDK (Side by side), CMake.
3. Запомни путь к SDK, обычно `C:\Users\ИМЯ\AppData\Local\Android\Sdk`.

## Этап 3. Запуск игры

1. Скачай папку `hoopflight` (или архив `hoopflight.zip`) из рабочей папки чата и распакуй, например, в
   `C:\Users\ИМЯ\Documents\hoopflight` (путь лучше без русских букв и пробелов).
2. Godot → **Import** → выбери `project.godot` → **Import & Edit**.
3. Нажми **F5**. Откроется меню, дальше «ИГРАТЬ» → выбери режим.

Управление: пробел или ЛКМ — импульс вверх, Esc — пауза.
На телефоне — тап по экрану.

Прогресс (очки, купленные мячи, рекорды) сохраняется автоматически в
`%APPDATA%\Godot\app_userdata\Hoop Flight\hoopflight_save.json`.

## Этап 5. Сборка APK

### 5.1 Шаблоны экспорта
Godot → **Editor → Manage Export Templates → Download and Install** (~700 МБ).
Версия шаблонов = версия редактора.

### 5.2 Пути к инструментам
**Editor → Editor Settings → Export → Android**:
- **Java SDK Path** → папка JDK 17
- **Android SDK Path** → папка Android Sdk (внутри должен быть `platform-tools\adb.exe`)

### 5.3 Ключ подписи
В `cmd` (подставь свой путь к JDK):

```bat
"C:\Program Files\Eclipse Adoptium\jdk-17.0.13.11-hotspot\bin\keytool" -keyalg RSA -genkeypair -alias androiddebugkey -keypass android -keystore debug.keystore -storepass android -dname "CN=Android Debug,O=Android,C=US" -validity 9999 -deststoretype pkcs12
```

В **Editor Settings → Export → Android** укажи:
- Debug Keystore → путь к созданному `debug.keystore`
- Debug Keystore User → `androiddebugkey`
- Debug Keystore Pass → `android`

Ключ в git не кладём — он уже исключён в `.gitignore`.

### 5.4 Пресет экспорта
**Project → Export… → Add… → Android**:
- **Unique Name:** `com.твойник.hoopflight`
- **Name:** `Hoop Flight`
- **Orientation:** `Landscape`
- Внизу не должно быть красных сообщений.

### 5.5 Собрать и поставить
- **Export Project…** → сохрани `HoopFlight.apk`.
- На телефон: скинь файл через Telegram/Drive и установи (разреши «Неизвестные источники»),
  либо включи **Отладка по USB** (Настройки → О телефоне → 7 раз «Номер сборки»),
  подключи кабель и нажми значок Android в Godot справа вверху.

## Этап 6. Правки, которые легко сделать самому

Открой нужный файл в Godot (вкладка **Script**), поменяй число, нажми F5.

| Что хочешь | Файл | Строка |
|---|---|---|
| Мяч прыгает выше | `scripts/Modes.gd` | `"jump": -520.0` → `-580.0` |
| Слабее гравитация | `scripts/Modes.gd` | `"gravity": 1500.0` → `1300.0` |
| Медленнее разгон | `scripts/Modes.gd` | `"speed_gain": 5.0` → `3.0` |
| Шире проход | `scripts/Modes.gd` | `"gate": 64.0` → `78.0` |
| Больше огня | `scripts/Modes.gd` | `"fire_chance": 0.12` → `0.3` |
| Чаще божественные кольца | `scripts/Modes.gd` | `DIVINE_CHANCE := 0.012` → `0.05` |
| Серии срабатывают раньше | `scripts/Play.gd` | `COMBO_GHOST := 10` и соседние |
| Дешевле скины | `scripts/Skins.gd` | поле `"price"` у нужного мяча |
| Свой мяч | `scripts/Skins.gd` | скопируй любой словарь в `LIST`, поменяй имя, цвета и `ability` |
| Перегенерировать звук | `tools/gen_audio.py` | `python3 tools/gen_audio.py` (нужен numpy) |

## Частые ошибки

| Ошибка | Лечение |
|---|---|
| «Export templates not found» | версия шаблонов ≠ версия редактора, переустанови шаблоны |
| «No valid Java SDK» / странная ошибка Gradle | стоит не JDK 17 — поставь Temurin 17 и укажи путь |
| «SDK location not found» | неверный Android SDK Path (нужен тот, где `platform-tools\adb.exe`) |
| «Failed to read key from store» | неверный путь/пароль keystore (пароль `android`, алиас `androiddebugkey`) |
| Чёрный экран на телефоне | Project Settings → Rendering → Renderer: `Mobile` (в проекте уже так) |
| Нет звука на телефоне | проверь переключатели «Звук»/«Музыка» в меню и громкость мультимедиа |
| Хочу сбросить прогресс | удали `hoopflight_save.json` из `%APPDATA%\Godot\app_userdata\Hoop Flight\` |
| `git push` бесконечно просит логин | зайди через GitHub Desktop или создай Personal Access Token |
| Всё сломал | `git checkout -- .` (откат правок) или `git reset --hard HEAD` (к последнему коммиту) |
